# Understanding_Compilers_From_Scratch
Automated Compiler Design visualizer that generates visual PDF execution traces for lexical analysis DFAs, operator precedence parsing functions via DFS, and FIRST/FOLLOW grammar sets. 🚀

🛠️ Features Lexical Analysis Tracer: Visualizes DFA state paths. Logs lookahead retractions and token steps.
Operator Precedence Analyzer: Builds precedence matrices. Finds longest paths using DFS stack traces. Generates final f and g function tables.Grammar Parser Helper: Automatically computes FIRST and FOLLOW sets for any context-free grammar.Automated PDF Generator: Exports high-quality, step-by-step visual reports of the entire execution. 
🚀 How It Works
Input: Provide a source stream or a grammar definition.
Processing: The engine executes lexing, parsing, or grammar analysis.
Output: Automatically generates comprehensive visual asset reports.
